MOVE THE STUDENT DEMO TO YOUR MAC

EASIEST: PREPARED ZIP
1. Transfer supabase-login-demo.zip to the Mac and extract it.
2. Install Node.js 20 or newer from https://nodejs.org/.
3. Open Terminal, type cd followed by a space, drag the extracted login-demo
   folder into Terminal, and press Return.
4. Run: npm start
5. Open http://127.0.0.1:8772. Swagger: http://127.0.0.1:8772/swagger.
   Leave Terminal open. Ctrl+C stops the server. No npm install needed.
6. Sign in separately with the invented student accounts.

The prepared ZIP already includes public connection settings.
The database lives at Supabase, so existing quiz results are available on either
laptop. You do not need to create users or rerun SQL when moving computers.

OR CLONE FROM GITHUB
git clone https://github.com/RandRise/supabase-login-explained.git
cd supabase-login-explained/login-demo
npm start

If Git asks for Apple's command-line tools, install them and retry.
GitHub's automatic Download ZIP does not include connection settings.

On the original laptop: Connection > Export settings.
Transfer student-connection.public.json to the Mac.
On the Mac: Connection > Import settings.
This file has the public project URL/key only. Do not transfer browser sessions.

SWAGGER
Open API docs from the portal. Sign in on the portal, then click Use portal
session in Swagger. Both tabs must use the exact same host and port.
127.0.0.1 and localhost are different browser storage origins.
No Postman, Swagger account or separate installation is needed.

UPDATES
Stop the server, run git pull from the repository, then npm start again.
Preserve your own edits; do not blindly reset them.

REHEARSE ON THE ACTUAL MAC
Test login, quiz submission, reload, Swagger and missing-token denial.
Internet and an active Supabase project are required.
The commands are portable, but this version has not been run on macOS.
