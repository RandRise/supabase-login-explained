04 / POSSESSION HAS CONSEQUENCES

What can a token holder do?

These checks send real read-only requests to your Supabase project. They do not disable security or edit records.

Sign in as Alice and verify Bob's example in Setup first.

Does logout erase a stolen copy?

Capture the current token in memory, sign out, then replay the same token against the Data API.

No token captured. Reloading clears the copy.

A stolen access token can…

Read Alice's note while accepted by this API. In other apps it may also allow actions that Alice is permitted to perform.

It does not automatically…

Reveal her password, let its holder forge Bob's identity, or override correctly enforced access rules.

Refresh-token theft may extend access. A privileged user's token carries broader permissions. Some account actions may be possible; never describe token theft as harmless.

Supabase Data API normally accepts a copied JWT until its actual expiry even after logout. Extra server checks can change this. A failed request is not proof of expiry unless its error says so.
