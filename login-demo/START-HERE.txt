STUDENT PORTAL — START HERE

EXISTING TEAM PROJECT
The student schema is already installed in the dedicated login-explained-demo
Supabase project. Alice and Bob already exist. Do not rerun the SQL on that project.

1. Install Node.js 20 or newer.
2. Extract the prepared ZIP.
3. Open a terminal in the login-demo folder and run:
   npm start
4. Open http://127.0.0.1:8772.
5. Sign in as alice@test.invalid or bob@test.invalid using your demo password.
   Passwords are deliberately absent from the ZIP.
6. Open API docs to use Swagger at /swagger.

The prepared ZIP includes only the public connection URL/key.
A GitHub clone needs Connection > Import settings, or URL/key entered manually.
See MAC-SETUP.txt and PRESENTATION.txt.

NEW, SEPARATE TEST PROJECT ONLY
1. Create a Supabase test project.
2. Authentication > Users > Add user > Create user:
   alice@test.invalid and bob@test.invalid, invented passwords, Auto Confirm.
3. Run add-student-quiz.sql ONCE in that project's SQL Editor, after users exist.
   The SQL adds its own quiz tables/functions; earlier exercises are not required.
4. Enter the project URL and publishable key in Connection.
   Never use a secret or service_role key.
5. Test both users and the missing-token case before presenting.

No GitHub-to-Supabase integration is required. GitHub stores the code; Supabase
provides Auth and the database; the local Node process serves static files.

STARTUP PROBLEMS
Port busy: close the old server terminal, or choose another port.
macOS: PORT=8773 npm start
PowerShell: $env:PORT='8773'; npm start
Connect to the port printed by the server. Do not open index.html via file://.
Missing function / HTTP 404: check the project and schema installation.
Network error / no HTTP response: check internet or a paused Supabase project.
HTTP 401 after a long pause: sign out, sign in again, then reattach in Swagger.
