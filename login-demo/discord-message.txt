I changed the demo to a student portal so the login/token idea is easier to follow.

Alice and Bob take a short quiz and each sees their own result. Supabase handles the login, calculates the score, and checks who can read it.

There's also a Swagger page where we can run the same request with and without a token:
- no token: 401
- Alice's token: Alice's result
- Alice asking for Bob's result: 403
- a copied, unexpired Alice token can still act as Alice after logout

I'll present the demo. Google sign-in can stay with the person covering that section.

The ZIP includes the public connection settings. Install Node.js 20+, extract it, open a terminal in login-demo, and run npm start. Open http://127.0.0.1:8772. No npm install needed. I'll share the invented login details separately.
